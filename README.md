# Portabilizer

**Превращает установщик, пакет или архив в портативную папку: программа или игра запускается откуда угодно
и ничего не пишет в систему.**

*English: Portabilizer turns an installer, package or archive into a portable folder (`App` + `Data` + `Launch.bat`). The program or game runs from any place (a USB stick, another PC) and keeps its settings and saves next to itself.*

## Зачем это нужно

Обычная установка раскладывает файлы по `Program Files`, `AppData` и реестру. Такую программу нельзя просто скопировать
на флешку или на другой компьютер, а при переустановке Windows всё приходится ставить заново.

Portabilizer делает из установщика готовую папку:

- программа лежит в папке и работает без установки; её можно переносить, копировать и хранить как обычные файлы;
- настройки, сохранения и временные файлы остаются внутри этой же папки, а не раскиданы по профилю Windows;
- в систему ничего не устанавливается, права администратора не нужны (кроме тех программ, которые сами их требуют);
- старые версии игр и программ можно держать рядом и не бояться, что одна сломает другую.

## Что получится

Для каждой программы создаётся папка `Имя_portable`:

```
Имя_portable\
  App\          сама программа (распакованные файлы)
  Data\         её настройки, сохранения и временные файлы
  Launch.bat    запуск программы с перенаправлением AppData и профиля в папку Data
```

Запускать нужно `Launch.bat`. Он направляет `APPDATA`, `LOCALAPPDATA`, `USERPROFILE` и `TEMP` в `Data`, поэтому
программа считает эту папку своим профилем.

## Что можно превратить в портативную версию

- установщики `.exe` (Inno Setup, NSIS, WiX) и `.msi`;
- пакеты MSIX / APPX и их бандлы;
- архивы: rar, zip, 7z, tar, gz, cab, iso, в том числе многотомные (`.part1.rar`);
- обычные `.exe` без установщика.

Программа сама определяет тип файла и распаковывает его **без установки в систему** (через 7-Zip, innoextract или
`msiexec`). Если установщик нельзя распаковать (например, репак с внешними `.bin`), она тихо ставит его прямо в
папку `App`. Главный exe находится автоматически; если вариантов несколько, окно предложит выбрать.

## Режимы

| Режим | Что делает |
|---|---|
| Авто | Сначала распаковка; если нужна установка (репак), пробует её, а распакованное сохраняет в папке `Extracted` |
| Только распаковка | Без установки |
| Только установка | Тихая установка в `App` (Inno / NSIS, при необходимости с запросом прав) |
| Только Launch.bat | Папка `*_portable` уже есть, нужно лишь создать запуск |
| **R (радикальный)** | После успешной сборки **удаляет исходный файл** (установщик, пакет или архив, все тома) и временные копии. Итог занимает меньше места. Перед запуском всегда спрашивает подтверждение |

Режим R удаляет только тогда, когда всё проверено: `Launch.bat` создан, распаковщик не сообщал о предупреждениях,
размер сходится. При ошибке или отмене исходник остаётся. Обычный `.exe` в режиме R не копируется, а
переносится в `App`.

## Что ещё умеет

- **Игры на Unreal Engine:** `Launch.bat` запускает нужный `...-Shipping.exe` напрямую, а не лаунчер или патчер.
- **Библиотеки внутри программы:** если игре не хватает DirectX (старые и июнь 2010), Visual C++ (2010, 2012, 2013,
  2015-2022) или OpenAL, Portabilizer предложит положить нужные файлы **рядом с игрой**. Они вшиты в exe, интернет и
  права администратора не нужны, в систему ничего не ставится.
- **.NET:** если программе нужен .NET, которого нет на компьютере, создаются `Install_dotnet.bat` и `.ps1`: они
  скачивают нужный рантайм в папку `dotnet` внутри портативной копии.
- **Запуск без UAC** для программ, которые сами просят права администратора.
- **Темы оформления:** светлая, тёмная, красные для режима R, свой цвет; автопоиск установленного 7-Zip.
- **Проверка обновлений:** сообщает, что вышла новая версия.
- Окно и командная строка в одном `Portabilizer.exe`: без аргументов открывается окно, с аргументами это консольная утилита
  (`--radical --yes` для режима R).

## Как пользоваться

1. Скачайте `Portabilizer.exe` из [Releases](../../releases) (файл `Portabilizer-vX.Y.zip` - тот же exe в архиве вместе
   с иконкой режима R).
   Проще всего поставить [Portabilizer Launcher](https://github.com/Vanyok-gh/Portabilizer-launcher): он сам скачает
   нужную версию, проверит её и запустит.
2. Запустите `Portabilizer.exe`. Windows может показать предупреждение SmartScreen: нажмите «Подробнее»,
   затем «Выполнить в любом случае».
3. Укажите установщик или архив и папку, куда сложить результат.
4. Нажмите кнопку запуска и дождитесь конца. Готовая папка `Имя_portable` появится в выбранном месте.
5. Запускайте программу через `Launch.bat` внутри неё. Папку можно переносить целиком.

Если Portabilizer предложит положить библиотеки (DirectX, Visual C++, OpenAL), согласитесь: так игра запустится на
компьютере, где их нет, и ничего не придётся устанавливать.

## Для автора: как выпустить версию

1. Поднять `APP_VERSION` в `portabilizer_v8.py`, дописать раздел `## vX.Y` в `CHANGELOG.md`.
2. Создать тег `vX.Y` (Releases -> Draft a new release -> новый тег -> Publish, либо `git tag vX.Y && git push --tags`).
3. GitHub сам соберёт `Portabilizer.exe` (`.github/workflows/release-portabilizer.yml`) и создаст релиз с описанием из CHANGELOG.

Локальная сборка: `build.bat` (нужны Python, `7z.exe` + `7z.dll` рядом, по желанию `innoextract.exe`). Наборы библиотек
для папки `dx` собирает `tools\collect_redist.bat`.
