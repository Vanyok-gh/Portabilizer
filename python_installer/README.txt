Положите сюда установщик Python (python-3.xx.x-amd64.exe) с python.org.
Если Python не установлен, build.bat предложит поставить его отсюда (для вашего пользователя, без прав администратора).
Для готового Portabilizer.exe Python не нужен: он встроен в exe. Python нужен только для сборки exe через build.bat.
